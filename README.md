# ML Elective Repository

This project is the collection of models and notebooks for the ML Elective course throughout the semester.

## Project Structure

```text
ML_Elec/
├── datasets/
│   ├── areas.csv       # Area values used for predictions
│   └── data_lr.csv     # Training data with area and price
├── notebooks/
│   ├── 1_linear_regression.ipynb
│   └── predictions.csv # Predicted prices generated by the notebook
├── python_vscode_jupyter_workflow.md
├── requirements.txt
└── README.md
```

## Workflow

1. Load `datasets/data_lr.csv`.
2. Train a scikit-learn `LinearRegression` model using area as the input
   feature and price as the target.
3. Read the area values from `datasets/areas.csv`.
4. Generate predicted prices.
5. Save the results to `notebooks/predictions.csv`.

## Requirements

- Windows
- Python 3
- VS Code
- Python and Jupyter VS Code extensions

The project dependencies are listed in `requirements.txt`, including
Jupyter, pandas, NumPy, matplotlib, and scikit-learn.

## Setup

Open the project folder in VS Code, then create and activate a virtual
environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install ipykernel
```

Select `.venv\Scripts\python.exe` as the Python interpreter and notebook
kernel in VS Code.

## Run the Project

1. Open `notebooks/1_linear_regression.ipynb`.
2. Confirm that the notebook kernel uses the project `.venv`.
3. Restart the kernel.
4. Run all cells from top to bottom.

The notebook reads the training data using a path relative to the
`datasets` folder and writes `predictions.csv` in the `notebooks` folder.

## Data Files

- `datasets/data_lr.csv`: training observations containing `area` and
  `price`.
- `datasets/areas.csv`: area values used to create new predictions.
- `notebooks/predictions.csv`: predicted prices for the values in
  `datasets/areas.csv`.
